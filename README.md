# GNW Evanston 2026 — online sharing deck

HTML slide deck for the 25 Aug 2026 online sharing with prospective Guanghua–Kellogg EMBA students.

- `index.html` — the whole deck, single file (CSS + JS inline)
- `assets/img/` — compressed photos + GK logo lock-ups
- `assets/video/` — short clips from the week

## Controls

| key | action |
| --- | --- |
| `→` / `Space` / click | next |
| `←` | previous |
| `O` | slide overview grid |
| `F` | fullscreen |
| `?static=1` | freeze all animations (for screenshots / PDF export) |

## Design

Palette sampled from the official GK cover artwork: Guanghua crimson `#B12D29` → Kellogg purple `#4E2A84`.
A lifted variant (`--gk-text`) is used for type, because the brand colours are too dark to read on near-black.
